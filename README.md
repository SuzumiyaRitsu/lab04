# 郑杰文 · 个人作品集

一个基于原生 HTML、CSS 与 JavaScript 的个人作品集网站，用于展示个人介绍、AI 辅助开发方向与项目作品。页面采用「桌面端左侧固定窄栏 + 右侧纵向内容流」的双栏布局，并在移动端自动切换为上下抽屉式导航，兼顾桌面端与移动端体验。

## 项目简介

郑杰文（Jiewen-Zheng）个人作品集，主要面向软件工程专业背景与 AI 辅助开发、大语言模型应用方向的求职与展示场景。网站集中呈现个人信息、技能方向，并以数据驱动方式渲染精选项目，支持深浅色主题切换。

## 功能特性

- **个人介绍 Hero**：展示姓名、专业方向与个人简介，并提供「查看项目作品」「联系我」入口。
- **项目作品展示**：通过 `js/projects.js` 中的数据结构驱动渲染，每条项目展示标题、简介、技术栈标签、类别与完成时间；新项目只需在数据数组中追加对象即可自动渲染。
- **项目类别与标签**：项目卡片以类别标签（小程序 / Web 应用 / 数据可视化 / AI 应用）+ 技术栈标签区分展示。
- **滚动导航高亮**：滚动页面时自动高亮当前所在章节对应的左侧导航项。
- **移动端抽屉菜单**：窄屏（≤ 900px）下切换为顶部栏 + 侧滑抽屉导航，支持点击遮罩、导航链接或 Esc 关闭。
- **深浅色主题切换**：右上角按钮在浅色 / 深色主题间切换，主题选择通过 `localStorage` 持久化，下次访问自动恢复。
- **响应式布局**：兼容桌面端与移动端，项目列表在窄屏下自动单列显示。

## 技术栈

- **HTML**：语义化页面结构
- **CSS**：自定义属性（CSS 变量）实现统一配色与主题切换，`Grid` / `Flexbox` 实现双栏、抽屉与内容布局
- **JavaScript**：原生脚本，负责数据驱动渲染、移动端菜单交互、滚动高亮与主题切换
- **无任何第三方 UI 库或前端框架**，纯原生实现，页面保持轻量

## 运行方式

本项目为纯静态网页，无需安装依赖或编译构建。

### 方式一：直接打开

用浏览器直接打开 `index.html` 即可浏览页面。

### 方式二：本地服务器（推荐）

建议通过本地 HTTP 服务器访问，避免部分浏览器对本地文件的限制（如 `localStorage` 在 `file://` 协议下可能不可用）。在项目根目录执行：

```bash
# Python
python -m http.server 8000
```

然后访问 http://localhost:8000

```bash
# Node.js
npx serve .
```

### 新增项目

在 `js/projects.js` 的 `projects` 数组末尾追加对象即可：

```javascript
{
  name: "项目名称",
  desc: "项目简介",
  stack: ["技术栈1", "技术栈2"],
  category: "项目类别",
  date: "2026-09",
  image: "图片地址",
}
```

保存后刷新页面即可看到新项目自动出现在「项目作品」区域。

## 项目规则

本项目遵循原生开发规范，不使用 React / Vue 等前端框架，也不引入第三方 UI 组件库；HTML、CSS、JavaScript 分别存放于对应文件；新增功能需在浏览器中验证，并尽量不破坏既有功能与页面结构。
